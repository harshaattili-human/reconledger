# ReconLedger

A Java/Spring Boot service for comparing two sets of transaction records and
reviewing exceptions. The first milestone is a local, deterministic prototype:
exact decimal matching, retry-safe batch creation, and transactional review history.

Independent portfolio project by Harsha Attili, developed with AI coding assistance.
All examples are synthetic. No employer code, production records, or customer data
are used. The service does not move money or execute financial transactions.

Implementation and validation are in progress. Run instructions and measured test
results will be recorded when the first working milestone is verified.
